# Team notes

Our own working material: brainstorms, idea docs, draft slides, meeting notes, persona thinking.

| Put it in | What |
|---|---|
| `Datathon2026Infos/` | Official material (brief, starter pack) and our slides. Don't edit the official files. |
| `notes/` (here) | Our own ideas, drafts, research, meeting notes. Anything goes. |
| `deliverables/` | Final submissions: one-pager, technical doc, video script, pitch deck. |

Tips: prefer Markdown (`.md`) so agents and teammates can read and diff it. Slides (`.pptx`/`.pdf`)
are fine too. `.csv`, `.xlsx`, `.zip` are gitignored, so put data in `data/` and export
spreadsheets you need to keep as `.md` or `.pdf`. Never put API keys or AWS credentials here.
